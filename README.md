# Ferme-El-Hadji-Abdou-Aziz-Bara-mbacke-
Ferme El Hadji Abdou Aziz Bara est une application Android de gestion agricole et d’élevage située à Touba, Sénégal. Elle permet de gérer les animaux, les dépenses et les recettes en FCFA, les commandes, les ventes, les stocks d’aliments, les soins vétérinaires et les rapports financiers hebdomadaires, mensuels
